# Somil Garak — Career Portfolio

A personal portfolio website built to showcase my transition from interstate heavy-vehicle driving and construction work toward a career as a Correctional Officer with the Tasmania Prison Service.

**Live site:** https://somilror200.github.io/somil-garak-portfolio/

## About

I'm an MC-licensed interstate driver (Angad Transport, Melbourne) and concreter/site supervisor (Subcon Pty Ltd), based in Ballarat, Victoria, Australia. This site brings together my experience, skills, and certifications in one place, and lays out how that background lines up with a career in corrections.

## Sections

- **Hero** — introduction and quick facts
- **About** — background and career-transition story
- **Experience** — timeline of driving and trade work
- **Skills** — transferable skills and licences/certifications
- **Career Goal** — target role (Correctional Officer, Tasmania Prison Service) and why my experience fits
- **Contact** — email, phone, and location

## Tech Stack

Plain HTML5, CSS3 (custom design tokens, light/dark mode), and vanilla JavaScript — no build step or framework required. Fonts via Google Fonts (DM Serif Display, DM Sans). Images generated for hero and section visuals.

## Running Locally

Any static file server works, e.g.:

```bash
npx serve .
```

Then open the printed local URL in a browser.
