# Somil Garak

A personal story site for Somil Garak.

This is intentionally **not** a conventional developer portfolio. It combines Somil's background in construction and interstate transport with his current Computer Science studies and direction into technology.

**Live site:** https://somilror200.github.io/somil-garak-portfolio/

## What the site focuses on

- Personal journey from India to Australia
- Bachelor of Computer Science at Deakin University
- Application Development and practical software skills
- Construction and transport as background, not career identity
- Current direction into software and technology roles

## Stack

- Semantic HTML
- Modern responsive CSS
- Vanilla JavaScript
- Light/dark theme
- Scroll-reveal interactions
- No framework or build step required

## Run locally

Open `index.html` directly, or serve the folder with any static HTTP server.
